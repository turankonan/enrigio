# Logos

The AnswerEcho mark: a lowercase "a" in Ubuntu Bold, ink #32373c, on the brand-green #39b54a field.

- `answerecho-icon-512.png` — the faithful rendering; use this anywhere the mark is displayed outside the app.
- `answerecho-icon.svg` / `answerecho-icon-maskable.svg` — the favicon and PWA maskable sources from `apps/web/public/icons/`. Their embedded Ubuntu font was stripped on upload, so the glyph may render in a fallback face; regenerate from `apps/web/scripts/generate-brand-icons.tsx`.

Never recolor the mark, and never put white text on the green field.
