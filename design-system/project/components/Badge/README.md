# Badge

Small status and category labels — model names, citation state, sentiment. Static rendition hand-styled from `packages/ui/src/components/badge.tsx` (shadcn Badge via `@workspace/ui/components/badge`).

- Because green doubles as the brand accent, a green badge alone can't signal success: pair it with an icon or explicit label text (the ▲ in the sample stands in for a Phosphor icon).
- Outline variant for neutral categories (model names, platforms); destructive for failures only.
