# Input

Text input paired with Label for all form fields. Static rendition hand-styled from `packages/ui/src/components/input.tsx` (shadcn Input via `@workspace/ui/components/input`).

- 36px height, `input` border, `radius-md`; focus shows the green `ring` at 2px.
- Labels sit above the field at 14px/500; helper and error text at 12px below.
- Consumers provide validation (via the Form component) and placeholder copy written as a real example, not an instruction.
