How the platform works · end to end

Measuring how AI answers talk about your brand.

Enrigio asks the AI engines people actually use — ChatGPT, Gemini, Perplexity, Google AI Overviews, Claude — the questions your customers ask, then measures how often they mention you, who they mention instead, and which sources they trust. Every day, automatically. Here's the whole machine, no code required.

Worked example: Rigosis — ITSM consulting, Turkey 7 answer engines 1 URL in → a daily scorecard out

01

The AI prepares the questions

You never write the prompts yourself. You give Enrigio a website; it reads the page, searches the web to verify what the company does, and proposes the search-style questions real people would type. For rigosis.com it came back with 20 suggestions about ITSM consulting and OpenText SMAX partnerships. You keep the ones that matter.

The trick is the mix. Most questions deliberately don't contain your name — because the real test is whether AI recommends you unprompted when someone asks about your category. A few branded ones ("rigosis alternative") check what AI says when asked about you directly.

Reads the real site

It pulls the actual page text (rendering JavaScript when needed) so the questions fit the real business, not a guess from the domain name.

Verifies with web search

The research model is allowed to search the web and is told: never invent — return nothing when unsure. Accuracy over confidence.

Finds competitors too

The same pass proposes competitors. If it's unsure it stays silent — later, a separate step discovers them from the answers themselves.

02

Every day, it asks every engine

Once tracking starts, each question fans out to every AI engine you've enabled — and asks each one several times, because AI answers vary. One Rigosis question became ~35 evaluations a day (7 engines × 5 runs). Nothing waits on you.

It reschedules itself. Each run books its own next run (default: every 24 h). A background safety-check every 5 minutes re-queues anything that fell behind — so tracking keeps going with no cron to babysit.
03

How it decides "you were mentioned"

No magic. Enrigio reads each answer as plain text and checks whether your name, a nickname, or your domain appears anywhere in it — and does the same for every competitor. Simple and robust, because AI writes prose, not tidy labels.

“For ITSM and OpenText SMAX projects in Turkey, established implementation partners include Rigosis, which specializes in service management and observability, alongside firms such as Konsalt and Kafein. Rigosis is based in Istanbul…”
✓ Brand mentioned — the text contains “rigosis”
Competitors found: Konsalt, Kafein

This is why a good brand name matters: matching is a plain text search. "Rigosis" is easy; a generic word would be noisy.

05

Turn results into a work list

The first run isn't a report card — it's a to-do list. Two features close the loop.

◎

Discover competitors from answers

Enrigio re-reads the stored answers and suggests every rival the engines named — each with a quote as evidence. On the Rigosis data it surfaced 15 candidates including Konsalt (28 runs) and Kafein (9) that a manual read had missed. Five were configured, so the next run produced an honest Share of Voice.

↗

Opportunities

A prioritized, auto-refreshing version of the work list: which questions you're losing, which sources to get cited on, where the quick wins are. Then the loop runs: act → the daily runs re-measure → watch the trend lines move.

06

What it costs to run

Measured from the Rigosis run — 5 prompts, one full daily cycle across 7 engines. Cost is mostly the engine calls; infrastructure was free-tier.

Rule of thumb

≈ $0.28 per prompt per day with all 7 engines at 5 runs each → about $8.50 / prompt / month at daily cadence.

20 prompts ≈ $170/month; dropping to the 5 scraped engines only ≈ $3.50 / prompt / month.

Every single call is logged for exact cost attribution, and a daily spend ceiling stops runaways automatically.
